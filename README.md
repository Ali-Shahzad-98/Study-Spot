# StudySpot (CIS4034-N Mobile App Development)
Student: F5485349 · Package: `uk.ac.tees.mad.f5485349`

Kotlin + Jetpack Compose app that helps students find study spots on campus.

## Sprint 1 – skeleton app
Splash -> Home (list) -> Detail (spot id passed via Navigation Compose) -> Favourites placeholder.
Sample data in `SpotRepository`; no permissions; no network.

## Run
Open the `StudySpot` folder in Android Studio (File > Open), let Gradle sync, press Run.
